# EarneyIT Support — Releases

Public release artifacts for the [Earney IT Support](https://github.com/Earney-IT/EIT-WIN-SUPPORT) Windows tray application.

This repository contains **release binaries only** — the application's source code is private. See the [Releases](https://github.com/Earney-IT/EIT-WIN-SUPPORT-releases/releases) tab for downloadable installer packages.

## What is this?

The Earney IT Support app is a Windows system tray application deployed to endpoints managed by Earney IT. It allows end users to submit support tickets directly to our helpdesk. This repo exists solely so the auto-update mechanism in the app can fetch new releases without shipping authentication credentials in the binary.

## For end users

You should not need to download anything here directly — the app updates itself automatically. If you are a customer and have not been told about this app, you can safely ignore this repo.
